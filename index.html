About PEVision

A professional-grade Portable Executable analyzer built for security researchers, malware analysts, and reverse engineers.

What is PEVision?

PEVision is a browser-based PE file analysis tool inspired by utilities like CFF Explorer and PE-bear. It provides deep inspection of Windows executable files including DOS/NT headers, section tables, import/export directories, cryptographic hashes, impHash, entropy analysis, and suspicious API detection — all without requiring any software installation.

Whether you're triaging a suspicious sample, learning PE file structure, or performing quick static analysis during an incident response, PEVision gives you the critical information you need in a clean, responsive interface.

Capabilities

  • File hashes — MD5, SHA-1, SHA-256, and ImpHash
  • DOS, NT, File, and Optional header parsing
  • Section analysis with entropy and RWX detection
  • Import and export table enumeration
  • Suspicious API flagging (VirtualAlloc, CreateRemoteThread, etc.)
  • Data directory and TLS information
  • Architecture detection (x86 / x64)

Privacy & Security

PEVision runs entirely in your browser using JavaScript. Your files are never uploaded to any server. All analysis is performed locally on your machine, making it safe to analyze sensitive or confidential samples.
